# Security policy

## Public repository scope

This repository contains public product documentation only. It does not contain
the Vision CoDev application or its production infrastructure.

## Reporting a concern

Please do not disclose suspected vulnerabilities, credentials, private links,
customer information, or sensitive deployment details in a public issue or
Discussion.

Use GitHub's private vulnerability reporting feature for this repository if it
is enabled. Otherwise, contact the repository owner privately through the
contact method on their GitHub profile.

Include only the information needed to understand and reproduce the concern.
Do not access, copy, or alter data that does not belong to you.

## Response expectations

Receipt of a report will be acknowledged when practical. Validation and timing
will depend on the affected system, severity, and whether the report concerns a
Vision CoDev-controlled environment.
